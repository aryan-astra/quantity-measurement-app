# Quantity Measurement App

Branch-wise Java assignment solutions are organized by use case branch.

## Branch Map

| Branch | Use Case | Focus |
| --- | --- | --- |
| UC1 | UseCase1QuantityMeasurementApp | Feet equality |
| UC2 | UseCase2QuantityMeasurementApp | Feet and inches equality |
| UC3 | UseCase3QuantityMeasurementApp | Generic quantity class (DRY) |
| UC4 | UseCase4QuantityMeasurementApp | Extended unit support |
| UC5 | UseCase5QuantityMeasurementApp | Unit conversion same type |
| UC6 | UseCase6QuantityMeasurementApp | Addition of two length units |

## Compile and Run

```bash
# Example for UC3
git checkout UC3
javac src/UseCase3QuantityMeasurementApp.java
java -cp src UseCase3QuantityMeasurementApp
```

Replace `3` with any target use case number.
